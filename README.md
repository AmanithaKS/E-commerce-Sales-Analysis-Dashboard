# E-commerce Sales Analysis Dashboard — Power BI

Analyzed global e-commerce sales data to identify revenue trends, 
profit margins, and regional performance across markets and categories.

## Business Problem
Which regions and product categories drive the most sales? 
Where are profit margins lowest despite high sales volume?

## Key Metrics
| Metric | Value |
| :--- | :--- |
| Total Sales | $12.64M |
| Total Profit | $1.47M |
| Total Quantity | 178K |
| Shipping Cost | $1.35M |

## Key Findings
- USA leads with 29% of total sales ($2.3M)
- APAC is the largest market at 28.36% ($3.59M)
- Technology is the top selling category
- Standard Class shipping dominates at $7.58M
- Shipping cost is 10.7% of total sales — worth monitoring

## Tools Used
- Power BI — dashboard and visualization
- Power Query — data cleaning and transformation
- DAX — KPI calculations
